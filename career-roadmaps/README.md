# Career Roadmaps: Remote IT First, Cybersecurity Next

This roadmap is built for a beginner in the Philippines with basic past web-dev exposure, no degree, no certs, no professional IT/cybersecurity experience, a $0 budget, and about **2–4 hours/day, 5 days/week**.

## The Strategy

You have three linked goals, taken in order:

1. **Goal A — IT first, 3–6 months:** land a remote entry-level IT role such as helpdesk, IT support, service desk, junior NOC, or junior sysadmin assistant.
2. **Goal B — Cybersecurity next, 6–18 months:** build toward SOC Analyst L1, junior GRC, IT security analyst, or junior pentest trainee roles while you gain real IT experience.
3. **Goal C — Mid-level next, years 1–3 of the job:** once you hold a security role, move from working tickets to owning outcomes. This is the third track, `advance-roadmap/`, and it is deliberately **not** for someone who has not worked in the field yet.

The honest hiring-manager view: cybersecurity is possible without a degree, but it is rarely the first job. Your fastest practical path is:

```text
basic IT skills -> remote IT/support job -> real tickets + users + systems -> cyber labs + portfolio -> entry-level cyber applications
```

## How to Use Both Roadmaps Together

### First 12–24 weeks

- Spend **80%** of your time on `it-roadmap/`.
- Spend **20%** on light cyber foundations only.
- Start applying for IT jobs after IT Phase 4, while continuing later phases.

### After you get an IT job

- Keep the job stable first.
- Study cyber **5–8 hours/week**.
- Turn your work experience into security stories: MFA issues, suspicious emails, endpoint problems, account lockouts, password resets, access requests, logs, and ticket documentation.

| Day | Focus | Time |

| Friday | Portfolio/resume/applications | 2–3 hrs |
| Weekend | Rest or optional catch-up | 0–2 hrs |

## When to Apply

Do **not** wait until you feel fully ready. Start applying for IT roles when you have:

- 3 troubleshooting write-ups
- 1 Windows or Linux VM lab screenshot
- 1 basic network diagram
- 1 resume
- 1 LinkedIn profile
- Basic confidence with Windows, Linux, networking, and ticket writing
