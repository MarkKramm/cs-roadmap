# Cybersecurity Master Checklist

Use this flat checklist to track the full cybersecurity roadmap.

## Cybersecurity Foundations

- [ ] I can explain CIA triad.
- [ ] I can explain risk, threat, vulnerability, exploit, and control.
- [ ] I created a 50-term glossary.
- [ ] I enabled MFA on important accounts.
- [ ] I summarized OWASP Top 10.
- [ ] I summarized 5 MITRE ATT&CK techniques.
- [ ] I wrote a phishing analysis report.
- [ ] I understand legal boundaries for labs.

## Networking and Linux

- [ ] I can explain OSI/TCP-IP models.
- [ ] I understand IPv4, IPv6 basics, DNS, DHCP, NAT, TCP, UDP, ICMP, HTTP, TLS.
- [ ] I can use Linux permissions and users.
- [ ] I can SSH into my own VM.
- [ ] I can use Nmap safely on my own lab.
- [ ] I captured and explained DNS traffic.
- [ ] I completed Bandit levels 0–10.

## Security Fundamentals

- [ ] I understand identity security basics.
- [ ] I understand endpoint security basics.
- [ ] I understand network security basics.
- [ ] I understand OWASP Top 10 at a basic level.
- [ ] I completed 5 PortSwigger labs.
- [ ] I inspected Windows security/process logs.
- [ ] I summarized 5 CVEs.
- [ ] I wrote a mock incident timeline.

## Hands-On Labs

- [ ] I built a lab diagram.
- [ ] I installed at least one Linux VM.
- [ ] I installed Wazuh or documented why hardware blocks it.
- [ ] I forwarded logs from a VM.
- [ ] I generated safe test events.
- [ ] I wrote 3 detection rules or rule modifications.
- [ ] I completed 10 PortSwigger labs.
- [ ] I completed 2 blue-team labs.
- [ ] I wrote one incident report.

## Specialization Choice

- [ ] I explored SOC/Blue Team.
- [ ] I explored GRC.
- [ ] I explored IT Security Analyst work.
- [ ] I explored Junior Pentest labs.
- [ ] I reviewed 20 job posts.
- [ ] I chose one primary path.
- [ ] I chose one backup path.
- [ ] I wrote a 90-day specialization plan.

## Portfolio Projects

- [ ] I created a cyber portfolio repo/folder.
- [ ] I completed Wazuh SIEM lab report.
- [ ] I completed network traffic analysis report.
- [ ] I completed an incident report.
- [ ] I completed at least one specialization project.
- [ ] I included screenshots/evidence.
- [ ] I included remediation advice.
- [ ] I can explain every project in interviews.

## Certifications

- [ ] I checked current official pricing.
- [ ] I compared certification requirements against job posts.
- [ ] I completed free training first.
- [ ] I mapped knowledge gaps.
- [ ] I have hands-on projects independent of the certificate.
- [ ] I decided whether to take an exam or delay.
- [ ] I will not claim a certification before earning it.

## Job Application

- [ ] I chose a primary cyber role family.
- [ ] I created a targeted cyber resume.
- [ ] I linked 3–5 completed projects.
- [ ] I updated LinkedIn/GitHub.
- [ ] I created an application tracker.
- [ ] I applied to at least 50 targeted roles over time.
- [ ] I practiced technical and behavioral interviews.
- [ ] I honestly separate labs from professional experience.

## Depth Track (optional — take the ones that match your Phase 5 choice)

### Cloud and Identity Security

- [ ] I can explain the shared responsibility model and where my responsibility starts.
- [ ] I built a least-privilege IAM role and can justify every permission in it.
- [ ] I enabled MFA in a free cloud tenant, and I can explain what a conditional access policy does and where the free tier stops.
- [ ] I found and fixed a public storage bucket in my own tenant.
- [ ] I read cloud audit logs (CloudTrail or Activity Log) and identified a suspicious action.
- [ ] I can explain the metadata service and why SSRF against it matters.

### Detection Engineering

- [ ] I can name the log source that answers a given question.
- [ ] I know the core Windows event IDs and what each one proves.
- [ ] I deployed Sysmon and can explain three of its event IDs.
- [ ] I wrote a detection rule from scratch and tested it against generated events.
- [ ] I tuned a noisy rule and documented what I changed and why.
- [ ] I mapped a detection to a MITRE ATT&CK technique.

### Incident Response and DFIR

- [ ] I can name the phases of the incident response lifecycle.
- [ ] I can state the order of volatility and why it matters.
- [ ] I preserved evidence with a documented chain of custody.
- [ ] I captured a forensic image and verified its hash.
- [ ] I built a timeline from logs across at least two sources.
- [ ] I wrote a full incident report with findings and recommendations.
- [ ] I ran or took part in a tabletop exercise.

### Scripting and Automation

- [ ] I wrote a Python script that parses a log file and reports something useful.
- [ ] I wrote a PowerShell command that triages a Windows host.
- [ ] I called an API and handled the response.
- [ ] I automated one repetitive part of my own triage work.
- [ ] I can explain when NOT to automate a task.
- [ ] I store secrets outside my scripts.

### GRC, Compliance and Risk

- [ ] I built a risk register with scored, justified entries.
- [ ] I can explain the difference between governance, risk, and compliance.
- [ ] I mapped controls from one framework to another.
- [ ] I wrote a policy a non-technical reader could follow.
- [ ] I collected evidence for an audit and can explain what each artifact proves.
- [ ] I can explain the privacy law that applies where I live.

### Web Application Security

- [ ] I can name and explain the OWASP Top 10 categories.
- [ ] I found and exploited SQL injection, XSS, and IDOR in a legal practice target.
- [ ] I used Burp Suite or ZAP to intercept and modify a request.
- [ ] I can explain the same-origin policy and why CORS misconfiguration matters.
- [ ] I wrote a web finding with reproduction steps and a specific remediation.
- [ ] I can state the authorisation rule for testing any system.
