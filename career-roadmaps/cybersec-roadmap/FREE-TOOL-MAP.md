# Free Tool Map

| Category | Paid Tool | Free Alternative | Trade-off |
|---|---|---|---|
| SIEM | Splunk Enterprise | Wazuh; Splunk free training | Wazuh needs setup; commercial Splunk has more enterprise integrations |
| SIEM | Microsoft Sentinel | Wazuh; Elastic free tier | No cloud-native Azure integration |
| Endpoint | CrowdStrike Falcon | Sysmon + Windows Defender logs | Less managed detection and response |
| Endpoint | Microsoft Defender for Endpoint | Sysmon + Defender built-in | Fewer centralized enterprise features |
| Web testing | Burp Suite Professional | Burp Community; OWASP ZAP | Fewer automated/scanning features |
| Vulnerability scanning | Nessus Professional | Nmap NSE; Greenbone CE | Setup and coverage can be harder |
| Network monitoring | Zeek commercial support | Zeek free/open-source | You manage installation and analysis |
| Network monitoring | Security Onion paid support | Security Onion free | Community setup required |
| ITSM | ServiceNow | osTicket; Google Sheets | Less enterprise workflow/reporting |
| ITSM | Zendesk | Freshdesk free; osTicket | Fewer automations/integrations |
| Labs | TryHackMe Premium | THM free rooms; PortSwigger; BTLO/CyberDefenders | Fewer guided rooms/AttackBox access |
| Password manager | 1Password | Bitwarden free; KeePassXC | Some team features require paid plan |
| Cloud lab | AWS/Azure paid usage | Free tiers; local VMs; Microsoft Learn sandboxes | Free quotas expire and require billing controls |
| Diagramming | Lucidchart paid | diagrams.net; Excalidraw | Fewer collaboration/templates |
| Resume/networking | LinkedIn Premium | LinkedIn free; JobStreet; Kalibrr | Fewer insights/InMail credits |
