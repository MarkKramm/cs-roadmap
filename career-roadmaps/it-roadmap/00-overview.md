# IT Roadmap Overview

## Goal

Land a remote entry-level IT job in **3–6 months**: helpdesk, IT support, service desk, technical support, junior NOC, or junior sysadmin assistant.

## Reality Check

You do not need to become an expert before applying. You need to prove you can troubleshoot, document, communicate clearly, and learn tools quickly.

## Timeline

| Phase | Topic | Realistic Time |
|---|---|---:|
| 1 | Computer fundamentals | 2 weeks |
| 2 | Operating systems | 3 weeks |
| 3 | Networking basics | 4 weeks |
| 4 | Helpdesk skills | 3 weeks |
| 5 | Sysadmin basics | 4 weeks |
| 6 | Tools and ticketing | 2 weeks |
| 7 | Soft skills | 1–2 weeks, then ongoing |
| 8 | Portfolio and resume | 2 weeks, then ongoing |
| 9 | Job application plan | 8–12 weeks alongside study |

Total: **12–24 weeks** depending on consistency, application response rate, and burnout weeks.

## Weekly Time Budget

- Minimum: 8 hours/week
- Good target: 10–15 hours/week
- Avoid: 25+ hours/week because you already know burnout is a risk

## What Counts as Job-Ready for Entry-Level IT

You are job-ready enough to apply when you can:

- Explain basic PC parts and common failures.
- Use Windows settings, Task Manager, Device Manager, Event Viewer, and command line basics.
- Use Linux shell for files, permissions, processes, services, and logs.
- Explain IPv4, IPv6 basics, DNS, DHCP, NAT, TCP/UDP, ports, Wi-Fi, and VPNs.
- Write a clear helpdesk ticket.
- Troubleshoot common issues: slow PC, no internet, login failure, printer issue, email issue, MFA issue.
- Use at least one ticketing tool demo.
- Show a small portfolio with screenshots and write-ups.

## Portfolio Artifacts to Build

Create a GitHub repo or Google Drive folder called `entry-level-it-portfolio` with:

1. PC parts one-page cheat sheet
2. Windows troubleshooting screenshots
3. Linux command cheat sheet
4. Basic home network diagram
5. DNS/DHCP troubleshooting write-up
6. 5 sample helpdesk tickets
7. Microsoft 365 or Google Workspace admin notes
8. Resume PDF

## Application Rule

Start applying after Phase 4. Do not wait until Phase 9. Application skill improves only by applying.

## What Comes After This Track

This track has one job, and it is worth being honest about what that means: **it gets you the first remote IT role.** It does not continue into a mid-level IT track, because this curriculum does not have one.

Where you go next depends on which job you want:

- **Security** — `cybersec-roadmap/` is the next track, and it is designed to run *alongside* your first IT job rather than after it. Your tickets become the material: MFA issues, suspicious emails, account lockouts, access requests, log reading. See [`../README.md`](../README.md) for how the two run together.
- **Staying in IT** — sysadmin, desktop engineering, identity and endpoint administration, M365 or cloud administration — there is no fourth track here, and no phase file waiting for you after Phase 9. The entry-level track gives you the job and the fundamentals; what you do with them from there is on the job, plus whatever vendor documentation and certification path your employer points you at.

Knowing that now is better than discovering it at the end of Phase 9. Neither answer is the wrong one — but only the security path has a track written for it.
