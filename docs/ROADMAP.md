## Explicitly out of scope

- Paid tools or resources that require a budget.
- Anything that adds a runtime dependency to read the content.
- Scope creep that makes the curriculum feel unachievable for a beginner.
- **Word-count ceilings on lessons.** 3,000 words is a floor. Longer, more detailed lessons are better; never trim a lesson to hit a target.
- **A mid-level IT track** (D-032). The three tracks are IT entry → cyber entry → mid-level cyber, and the third assumes the reader already holds a security role. There is deliberately **no fourth track** for the IT professional who stays in IT — sysadmin, desktop engineering, identity and endpoint administration, M365 or cloud administration. The strategy document states the intent in Goal C; what was missing was any statement *to the reader* that the IT path ends. That is now written in [`career-roadmaps/README.md`](../career-roadmaps/README.md) and in the IT overview's closing section.
  - This was raised as a possible oversight and investigated as one. It is not: `career-roadmaps/README.md` names the three goals in order and describes the mid-level track as "deliberately **not** for someone who has not worked in the field yet", with the path diagram showing IT as the on-ramp that produces *"real tickets + users + systems"* for the cyber track to convert.
  - **If a fourth track is ever wanted, D-032 is the record to amend.** It would be 5–7 phases and would need its own answer to "who is this for", because the current answer is a reader the strategy document does not set out to serve.
